# CPC — Visual Private Cloud

An on-premises private-cloud simulation and Site Reliability
Engineering (SRE) learning platform inspired by Ireland.

## Project principles

- Run locally on Ubuntu Server without AWS.
- Preserve existing home-server workloads.
- Use reproducible configuration and automated tests.
- Measure reliability instead of assuming it.
- Develop incrementally using Agile practices.

## Initial scope

1. Define service and infrastructure requirements.
2. Build a testable application with health endpoints.
3. Introduce metrics and operational dashboards.
4. Test failure detection and recovery.
5. Document incidents, SLOs and engineering decisions.
